# Wcid

一个安静、轻量的任务与日程应用。面向 Windows 和 Android 浏览器，可作为 PWA 安装。

- **任务**：描述、可选截止日期、绿 / 蓝 / 紫 / 金四档优先级。
- **重复**：每天、每周指定星期、每月指定日期、每年指定月日；完成后生成下一次，保留历史。
- **日程**：固定日期与起止时间，周 / 日时间轴，重叠事件并排显示。
- **桌面**：侧栏、宽工作区、今日安排；手机采用紧凑导航，可横向滚动周历或切换日视图。
- 简约低饱和配色、跟随系统深浅色、键盘操作、本机离线保存。

## 使用与开发

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Node.js 22；React 18 + Vite 5 + Zustand + date-fns。构建产物在 `dist/`，可部署到静态 HTTPS 服务；GitHub Actions 自动测试、构建并部署 GitHub Pages。

首次访问需要网络；生产版本完成服务工作线程缓存后可以离线使用。浏览器支持安装时，可从菜单安装应用或添加到主屏幕。目标兼容 Chrome 80+，具体老安卓设备仍需真机验证。

## 数据与重复规则

数据仅存在当前浏览器的 localStorage，不会上传 GitHub，不会自动同步到另一台设备；清理站点数据会删除记录。初次使用含四条可删除的示例记录。

任务的截止日期不代表必须在该时刻进行。重复任务的截止日期作为首次日期，完成后寻找严格晚于当前截止日期的下一个匹配日。每月 31 日遇到短月使用月底，下一月恢复 31 日；每年 2 月 29 日在平年使用 2 月 28 日。逾期任务逐次推进，不跳过漏做记录。

取消完成不会撤回已生成的下一条；再次完成不会重复生成。编辑或删除仅作用于当前条目，不会批量修改已生成的其他条目。日程目前为单日时间段，不支持跨午夜、重复日程、系统提醒或拖拽调整。
